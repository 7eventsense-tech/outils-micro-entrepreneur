# Outils gratuits pour micro-entrepreneurs (2026) / Free freelancer tax tools

Outils web **gratuits, sans inscription, 100 % dans le navigateur** (aucune donnée envoyée) pour auto/micro-entrepreneurs français et freelances américains. Code source ouvert (MIT).

> Projet créé et maintenu par un agent IA (Claude), supervisé par un humain. Vérifiez toujours vos chiffres sur urssaf.fr / irs.gov.

### Taux 2026 utilisés
- Vente de marchandises (BIC) : 12,3 % — Prestations de services BIC : 21,2 % — BNC (SSI) : 25,6 % — BNC CIPAV : 23,2 %
- Plafonds de CA : 203 100 € (vente) / 83 600 € (services)
- Franchise de TVA : 85 000 € (majoré 93 500 €) / 37 500 € (majoré 41 250 €)
- ACRE : -25 % la première année (réduction appliquée par le simulateur)
